**Planning v0.9.0 — exceptions conservées directement dans la carte**

Modifier **Toute la série** conserve désormais les jours déplacés et supprimés.
Les jours déplacés gardent leurs dates, horaires et actions particulières ; les
autres occurrences suivent les nouveaux réglages. Le glisser-déposer continue
de modifier uniquement le jour déplacé.

Aucun complément ou nouvelle intégration à installer. La carte utilise les API
natives Home Assistant et un journal partagé dans le même Calendrier local.
Ce journal est conservé au 3 janvier 2000 et masqué dans la carte. Le blueprint
d’exécution reste celui de la v0.6.0, sans réimportation nécessaire.

### Mise à jour et reprise de l’existant

1. Dans **HACS → Planning**, mettre à jour vers **v0.9.0**.
2. Recharger complètement le navigateur (**Ctrl+F5**) ou l’application Home Assistant.
3. Les séries créées avec cette version sont suivies automatiquement.
4. Pour une **ancienne série**, ouvrir **Toute la série → Importer les exceptions
   existantes**, puis sélectionner une copie récente du fichier **ICS complet**
   de ce Calendrier local, récupérée dans le dossier `.storage` de la configuration
   Home Assistant. Vérifier les horaires et enregistrer. Cette reprise se fait
   une seule fois par ancienne série, avec l’aide d’un administrateur pour le fichier.

L’API ne montre pas les jours déjà supprimés : sans cet import, la carte refuse
de remplacer une ancienne série dont l’historique est incomplet. Le fichier est
lu dans le navigateur ; seule la série sélectionnée est reprise.

### Sauvegarde et utilisation

Garder la carte ouverte jusqu’à la fin de l’enregistrement. La sauvegarde comporte
plusieurs appels API ; le journal permet de reprendre après une interruption au
prochain chargement. Les événements temporaires restent inactifs. Pendant une
interruption, certains horaires peuvent rester inactifs jusqu’à la reprise.

Après la reprise, gérer les exceptions depuis la carte. Les changements directs
faits dans le calendrier natif ne sont pas ajoutés automatiquement au journal.
Conserver les événements techniques lors des sauvegardes du calendrier.

### Validation

78 tests de logique, import et traduction ; 74 tests de blueprints et calendrier
natif ; quatre parcours navigateur. Les vérifications couvrent les exceptions

les utilisateurs classiques, la reprise après coupure et les quatre langues.
