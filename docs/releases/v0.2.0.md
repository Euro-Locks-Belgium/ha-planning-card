**Planning v0.2.0**

- Application renommée **Planning** dans HACS, le sélecteur de cartes et l'interface.
- Démarrage entièrement vide : aucun groupe, horaire, exclusion ni événement de démonstration prérempli.
- Formulaires vierges : choix explicite du groupe, de la date, de l'heure et du libellé d'exclusion.
- Ajout et retrait des groupes depuis l'éditeur visuel.
- Redimensionnement natif Home Assistant en vue Sections (largeur et hauteur).
- Adaptation à la largeur réelle de la carte, même dans une colonne étroite sur ordinateur.
- Compatibilité avec les cartes et les calendriers de la version 0.1.0.

Dans HACS, mettre à jour **Planning** puis recharger le navigateur.
Le dépôt et le fichier conservent leur identifiant existant pour permettre la mise à jour.

Nouvelle configuration minimale :

```yaml
type: custom:ha-planning-card
demo: true
groups: []
```

Pour agrandir : vue **Sections → Modifier la carte → Disposition / Layout**.
Une vue **Panneau / Panel** permet une page entière.

[Guide complet](https://github.com/Euro-Locks-Belgium/ha-planning-chauffe-card#readme).
Aucune donnée de calendrier existante n'est supprimée par la mise à jour et aucune modification de l'installation Home Assistant n'a été effectuée lors de cette publication.
