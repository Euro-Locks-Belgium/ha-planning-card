**Planning v0.9.1 — jours passés plus sombres**

Les journées jusqu’à hier ont un fond plus sombre dans les vues **Mois, Semaine
et Agenda**. Les programmations passées gardent leur couleur, atténuée avec un
contraste du texte recalculé. Aujourd’hui et les journées futures gardent leur
présentation habituelle.

La date suit le fuseau de Home Assistant, y compris à minuit lorsque le navigateur
utilise un autre fuseau. Un créneau encore en cours garde sa couleur normale,
même s’il a commencé la veille. Les styles Rempli, Contour et Point sont conservés.

Le [guide de reprise des anciennes séries](https://github.com/Euro-Locks-Belgium/ha-planning-card/blob/v0.9.1/docs/planning-series.md)
précise maintenant où récupérer le fichier `local_calendar.*.ics` et comment rendre
le dossier `.storage` visible dans File editor.

### Mise à jour

1. Dans **HACS → Planning**, mettre à jour vers **v0.9.1**.
2. Recharger complètement le navigateur (**Ctrl+F5**) ou l’application Home Assistant.

Le calendrier et son journal sont conservés. Une série déjà reprise en v0.9.0
ne nécessite pas de nouvel import ICS. Le blueprint d’exécution est inchangé ;
aucune réimportation ou installation de complément n’est nécessaire.

### Validation

78 tests de logique, import et traduction ; 74 tests de blueprints et calendrier
natif ; cinq parcours navigateur. Les vérifications visuelles couvrent les thèmes
clair/sombre, le mobile, le changement de jour dans le fuseau Home Assistant,
les créneaux en cours, la lisibilité des couleurs et les trois vues.

La publication GitHub ne modifie aucune instance Home Assistant et ne commande
aucun appareil.
