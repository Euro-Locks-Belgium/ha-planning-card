**Planning v0.4.0 — plusieurs horaires et sélection des appareils**

Chaque programmation peut avoir son libellé, sa couleur et sa sélection d'appareils.
Plusieurs séries hebdomadaires peuvent coexister dans le même calendrier : le
bouton **Ajouter un horaire** reste disponible. Un démarrage ponctuel peut
remplacer précisément une série pour une semaine.

- Menus heures/minutes avec minutes `00`, `10`, `20`, `30`, `40`, `50`.
- Anciennes minutes intermédiaires conservées à l'ouverture d'un événement.
- Appareils configurables dans l'éditeur de carte, sans données préremplies.
- Couleurs conservées sur toutes les occurrences d'une série.
- Mise en page adaptée aux cartes étroites et aux longues listes d'appareils.

### Mettre à jour la carte

1. Dans HACS, télécharger **Planning v0.4.0**.
2. Recharger complètement le navigateur ou l'application Home Assistant.
3. Conserver le calendrier actuel. Dans l'éditeur de carte, renseigner les noms
   et identifiants dans **Appareils programmables** si vous utilisez la sélection
   par programmation.

Le planning démarre vide. Le mode local permet d'essayer sans enregistrer dans
Home Assistant. La carte seule ne commande aucun appareil.

### Nouveau blueprint Frech

Importer séparément [Planning — démarrage Frech par programmation](https://github.com/Euro-Locks-Belgium/ha-planning-card/blob/v0.4.0/blueprints/planning-frech.yaml).

Configurer une seule automatisation pour le calendrier, le catalogue associant
les identifiants aux relais/entrées/numéros et le script de démarrage existant.
Conserver **Mode test = activé** pour les premiers essais : une notification
liste les appareils prévus, sans appeler le script.

Le blueprint appelle le script successivement pour les appareils sélectionnés,
avec 10 secondes d'attente dans le script et 60 secondes entre deux machines par
défaut. Le script existant conserve ses vérifications, secondes tentatives et
notifications. Une exclusion ou un événement annulé/modifié interrompt la suite
de la séquence à la relecture entre machines. Les programmations simultanées
passent dans une file et peuvent commencer plus tard.

HACS ne met pas à jour les blueprints et automatisations déjà importés. Les
blueprints à groupe fixe restent disponibles ; leurs versions mises à jour
refusent les événements portant une sélection d'appareils. Utiliser le nouveau
blueprint Frech pour cette sélection et remplacer les anciens horaires lors de
la bascule.

### Gestion des appareils

L'éditeur de carte permet de gérer les noms et identifiants. Les associations
techniques restent dans le catalogue du blueprint. L'écran complet de
configuration technique des appareils n'est pas inclus dans cette version.
Retirer un appareil de la carte ne supprime pas ses programmations existantes
et ne le retire pas du catalogue d'exécution.

### Validation

22 tests de logique, 42 scénarios de blueprint et essais navigateur réussis avec
des services simulés. Aucun appareil réel n'a été commandé et aucune configuration
Home Assistant n'a été modifiée lors de cette publication.
