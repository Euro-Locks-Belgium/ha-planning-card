Première version de test de **Planning de chauffe** pour Home Assistant.

- Carte HACS avec calendrier mensuel, fermetures, reprises ponctuelles et horaires hebdomadaires.
- Démonstration activée par défaut, sans accès aux calendriers ou aux relais.
- Calendriers locaux partagés pour l'utilisation connectée.
- Blueprint séparé pour l'exécution côté Home Assistant, en mode test par défaut.
- Fermetures prioritaires, remplacement du démarrage du cycle dimanche-samedi et vérification des événements annulés.
- 16 tests unitaires, 17 scénarios du blueprint et essais navigateur avec une API Home Assistant simulée.

### Installer pour tester

1. Dans HACS, ajouter `https://github.com/Euro-Locks-Belgium/ha-planning-chauffe-card` en dépôt personnalisé, type **Dashboard**.
2. Télécharger **Planning de chauffe** puis recharger Home Assistant dans le navigateur.
3. Ajouter une carte manuelle :

```yaml
type: custom:ha-planning-chauffe-card
demo: true
```

Le [guide complet](https://github.com/Euro-Locks-Belgium/ha-planning-chauffe-card#readme)
explique ensuite la création de calendriers dédiés et l'import du blueprint.
Le blueprint n'est pas installé automatiquement par HACS.

Cette publication n'a modifié aucune configuration ni aucun relais de l'installation Home Assistant.
Les essais d'exécution utilisent des services simulés ; aucune validation de démarrage réel n'est revendiquée.
