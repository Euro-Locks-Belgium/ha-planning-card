**Planning v0.2.1 — nouveau nom du dépôt**

Le dépôt devient **Euro-Locks-Belgium/ha-planning-card**, un nom correspondant à
la carte de planning générale pour Home Assistant.

- Historique, versions et discussions conservés par le renommage GitHub.
- Module installable : `ha-planning-card.js`.
- Configuration HACS et liens de documentation mis à jour.
- Ancien type `custom:ha-planning-chauffe-card` toujours compatible.

### Mise à jour

1. Utiliser `https://github.com/Euro-Locks-Belgium/ha-planning-card` comme dépôt
   personnalisé HACS, type **Dashboard**.
2. Télécharger **Planning v0.2.1**.
3. Dans les ressources du tableau de bord, vérifier le module JavaScript :

   `/hacsfiles/ha-planning-card/ha-planning-card.js`

4. Remplacer l'ancien chemin si nécessaire, puis recharger le navigateur.

Le [guide complet](https://github.com/Euro-Locks-Belgium/ha-planning-card#readme)
détaille l'installation. Aucune configuration de Home Assistant n'a été modifiée
par cette publication et aucun événement existant n'a été supprimé.
