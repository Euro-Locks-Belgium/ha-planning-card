**Planning v0.8.0 — modification des séries et calendrier compact**

Cliquer sur une programmation récurrente permet de choisir **Ce jour uniquement**
ou **Toute la série**. Le premier choix reste sélectionné par défaut. Le second
applique les horaires, actions et couleurs à la série et permet de choisir les
jours habituels d’une programmation hebdomadaire Planning.

**Vérifier la Date de début de la série avant Enregistrer la série.** Le remplacement
natif recalcule les occurrences depuis cette date et **réinitialise les jours
déplacés ou supprimés individuellement**. Le formulaire affiche cet avertissement
avant l’enregistrement. Les limites de répétition existantes restent dans la règle.

Le **glisser-déposer modifie toujours uniquement le jour déplacé**, quel que soit
le choix précédent dans le formulaire.

Les anciennes programmations affichent désormais leur couleur avant le survol.
Le survol assombrit cette couleur. Le calendrier est plus compact : cases moins
hautes, hauteur adaptée au contenu et échelle horaire réduite en vue Semaine.

### Mise à jour

1. Dans **HACS → Planning**, mettre à jour vers **v0.8.0**.
2. Recharger complètement le navigateur (**Ctrl+F5** sur ordinateur), ou
   l’application Home Assistant.
3. Cliquer sur une programmation pour choisir la portée de la modification.

Le calendrier et les automatisations existants restent utilisables. Le blueprint
d’exécution est inchangé depuis la v0.6.0 ; aucune réimportation n’est nécessaire
pour une installation déjà préparée.

### Validation

simulés, 9 tests du calendrier natif et quatre parcours navigateur. Les vérifications
couvrent les deux portées, les jours hebdomadaires, le traitement des exceptions,
les couleurs avant le survol, les vues compactes, les quatre langues et le
déplacement à la souris et au tactile.

La publication GitHub ne modifie aucune instance Home Assistant et ne commande
