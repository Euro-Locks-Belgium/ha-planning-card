**Planning v0.3.0 — un seul calendrier**

Un seul calendrier suffit pour ajouter des programmations et des exclusions.
Les groupes deviennent facultatifs : il n'est plus nécessaire d'en créer pour
commencer. Aucun événement n'est ajouté automatiquement.

### Pour utiliser votre calendrier

1. Mettre à jour **Planning** dans HACS, puis recharger le navigateur.
2. Modifier la carte et choisir **Calendrier du planning**.
3. Enregistrer puis cliquer sur **Ajouter une programmation** ou **Ajouter une exclusion**.

Configuration minimale :

```yaml
type: custom:ha-planning-card
calendar: calendar.mon_planning
```

Le choix du calendrier active le mode connecté. Le mode local reste disponible
pour tester sans enregistrer dans Home Assistant. Les champs de date et d'heure
restent vierges jusqu'à votre saisie.

### Pour exécuter les actions

Importer le nouveau blueprint **Planning - calendrier unique** depuis :

`https://github.com/Euro-Locks-Belgium/ha-planning-card/blob/v0.3.0/blueprints/planning.yaml`

Choisir le même calendrier que dans la carte. Laisser **Filtre de groupe** vide
si aucun groupe n'est configuré. Conserver le **Mode test** pour les premiers
essais. Le blueprint s'importe séparément ; HACS ne met pas à jour automatiquement
les automatisations déjà importées.

Le nouveau blueprint distingue les exclusions par leur type et ne confond pas
une programmation avec une fermeture. Les exclusions s'appliquent à tous les
groupes du calendrier. Les remplacements et doublons sont isolés par groupe.

Les anciennes configurations à plusieurs calendriers restent compatibles avec
leur blueprint historique. Aucun calendrier, événement ou appareil de votre
installation n'a été modifié lors de cette publication.
